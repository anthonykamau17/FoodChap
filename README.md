# FoodChap

A Kenyan meal-planning Android app built with Kotlin, Room, and MVVM.

## Features
- Browse 100+ recipes (Kenyan and global), with search and category filtering
- "What Can I Cook?" — select ingredients you have (priced at real Kenyan market rates) and get matching recipes with a yield estimate
- Step-by-step recipe instructions with built-in cooking timers
- Weekly meal planner
- Auto-generated shopping list with running KES cost total
- "Goes well with" recipe pairing suggestions
- Light and dark theme, toggleable in-app
- Onboarding walkthrough for first-time users

## Tech stack
- Kotlin, native Android (no Compose — XML/View-based UI)
- MVVM architecture with ViewModel + LiveData
- Room for local persistence
- Material Components

## Setup
1. Clone the repo
2. Open in Android Studio
3. Sync Gradle and run
